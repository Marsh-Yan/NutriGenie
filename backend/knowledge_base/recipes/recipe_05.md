# 麻婆豆腐

## 风味与口感

川味经典，豆腐嫩滑入味，麻辣鲜香。

整体步骤相对精简，适合工作日快速完成。

味道更有存在感，适合搭配米饭、杂粮饭或其他主食。

可作为素食取向的选择；具体是否严格素食以 MySQL 食材清单为准。

## 适合场景

- 适合午餐或晚餐作为主菜。
- 全部准备与烹饪时间约 18 分钟。
- 可搭配主食和蔬菜组成完整一餐。

## 烹饪特点

- 难度：easy；菜系：chinese。
- 可根据个人口味调整油、盐和辛辣程度；营养与成本以系统结构化计算结果为准。
